# Tour Agency Website

This is a responsive tour agency website built using HTML and designed to showcase various travel destinations and offers.

## Features
- Clean and modern design
- Responsive layout for both desktop and mobile devices
- Grid-based card layout for featured tours
- Easy navigation and call-to-action buttons

## Technologies Used
- **HTML5:** The structure of the website.
- **Tailwind:** For styling and responsive design.
